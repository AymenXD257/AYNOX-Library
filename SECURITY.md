# Security Policy

## Supported Versions

Security updates are provided for the latest available version of AYNOX Library.

Older versions may not receive security fixes.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

Please do not publish sensitive vulnerability details in a public GitHub Issue.

Instead, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

When reporting an issue, include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Relevant screenshots, logs, or proof of concept, if available.

## Response

The project maintainer will review the report and determine the appropriate next steps.

Please allow reasonable time for investigation and a possible fix before publicly disclosing the vulnerability.

## Responsible Disclosure

Please avoid exploiting vulnerabilities, accessing other users' data, or disrupting services.

Thank you for helping keep AYNOX Library secure.
