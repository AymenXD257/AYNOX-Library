# Contributing to AYNOX Library

Thank you for your interest in contributing to AYNOX Library! Contributions, suggestions, bug reports, and improvements are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork:

   ```bash
   git clone https://github.com/AymenXD257/AYNOX-Library.git
   ```

3. Open the project directory:

   ```bash
   cd AYNOX-Library
   ```

4. Install dependencies:

   ```bash
   flutter pub get
   ```

5. Create a branch for your changes:

   ```bash
   git checkout -b feature/your-feature-name
   ```

## How to Contribute

### Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue.
- Steps to reproduce it.
- Expected and actual behavior.
- Your device, operating system, and Flutter version.
- Screenshots or logs, if available.

### Suggesting Features

Feature suggestions should explain:

- The problem the feature would solve.
- How you expect it to work.
- Any relevant examples or references.

### Submitting Changes

1. Keep changes focused and easy to review.
2. Follow the existing Dart and Flutter code style.
3. Use clear and descriptive names.
4. Add or update tests when appropriate.
5. Run the available checks before submitting:

   ```bash
   flutter analyze
   flutter test
   ```

6. Commit your changes with a clear message.
7. Push your branch and open a Pull Request.

## Pull Request Guidelines

Please include:

- A concise description of the changes.
- The reason for the changes.
- Screenshots for relevant UI changes.
- Test results and any known limitations.

Please avoid unrelated changes in the same Pull Request.

## Code of Conduct

Be respectful, constructive, and considerate when communicating with other contributors.

## Questions

For questions or project-related discussions, open a GitHub Issue.

Thank you for helping improve AYNOX Library!
