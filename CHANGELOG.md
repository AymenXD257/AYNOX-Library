# AYNOX Library — Changelog & Engineering Audit

All bug repairs, architectural enhancements, and test verifications performed on AYNOX Library.

| Bug / Defect | Root Cause | Engineering Fix | Test Performed | Result |
|---|---|---|---|---|
| **Corrupt & incomplete downloads treated as complete** | `FileStorageService.downloadBookFile` wrote directly to final destination filename. On crash/abort, corrupt truncated file remained on disk and future checks `targetFile.exists()` returned true. | Implemented temporary `.part` file downloads, atomic rename on success, and magic bytes verification (`%PDF-`, valid EPUB ZIP structure, text encoding checks). Truncated/corrupted files are automatically purged. | `test/file_storage_test.dart` (`validateBookFile`) | **PASSED** |
| **Swallowing API errors silently** | APIs caught all exceptions with empty `catch (e) { return []; }` hiding rate limits, timeouts, and network disconnects. | Converted providers to throw explicit typed exceptions or record individual health diagnostics (`SourceDiagnostic`). | `test/book_source_test.dart` (`HTTP error throws readable exception`) | **PASSED** |
| **Fake search results fallback** | `DiscoveryProvider.search` replaced empty query results with `_featuredBooks` and `_arabicClassics`, misleading users searching for specific topics. | Removed deceptive fallback; empty search results honestly report zero matches with a clean empty state and retry button. | `test/book_source_test.dart` & `DiscoveryProvider` | **PASSED** |
| **Arabic Literature category broke Gutenberg search** | Gutenberg has no topic called "Arabic Literature"; Gutendex returned 0 results. | Normalized categories, mapped topics per provider, and routed Arabic queries to legitimate Arabic digital repositories. | `test/book_source_test.dart` | **PASSED** |
| **Curated Arabic books had missing download links** | `OpenLibraryService.getCuratedArabicClassics()` instantiated books with `format: 'txt'` but empty `downloadUrls`. | Implemented `ArabicHeritageSource` with verified, legally accessible download links (PDF & TXT) for all Arabic heritage masterpieces. | `test/book_source_test.dart` (`ArabicHeritageSource`) | **PASSED** |
| **Open Library records lacked fulltext links** | `Book.fromOpenLibrary` did not inspect fulltext availability or IA metadata. | Integrated Internet Archive identifiers (`ia`) from Open Library records to build working PDF, EPUB, and TXT URLs for open-access books. | `test/book_source_test.dart` (`OpenLibrarySource`) | **PASSED** |
| **Missing Pagination / Broken `_currentPage`** | `_currentPage` was never incremented; no "Load More" button or pagination logic existed. | Implemented scalable pagination (`loadMore()`, `hasNextPage`, `_currentPage`) across all providers in `DiscoveryProvider`. | `DiscoveryProvider.loadMore()` test | **PASSED** |
| **White-on-White text bug in Light Mode** | Hardcoded `Colors.white` and `Color(0xFF141A29)` on cards and screens produced unreadable white text on white backgrounds. | Replaced all hardcoded colors with theme tokens (`theme.colorScheme.onSurface`, `theme.colorScheme.surface`, `primary`). Tested in Light & Dark modes. | `AppTheme.lightTheme` & Widget tests | **PASSED** |
| **EPUB reading lost images and formatting** | `EpubParser` stripped all HTML tags (`<[^>]*>`), style elements, images, and TOC, reducing chapters to raw text strings. | Rewrote `EpubParser` to extract embedded images from ZIP archive, parse structured content blocks (headings, paragraphs, blockquotes, images), and build Table of Contents. | `test/epub_parser_test.dart` | **PASSED** |
| **EPUB/TXT lacked real pagination** | Chapters or text documents were rendered in an endless `SingleChildScrollView`. | Engineered `BookPageFrame` and `BookPageTurnView` providing paper-like realistic reading with running headers, footers, margins, and 3 page-turn modes (Page Curl, Slide, Scroll). | `test/reader_engine_test.dart` | **PASSED** |
| **Clear Cache deleted user books** | `SettingsProvider.clearCache` called `clearAllStorage()` which wiped the entire books directory. | Separated temporary cache (`getTempCacheDirectory`) from permanent user books (`getBooksDirectory`). `clearTemporaryCache()` only purges cache and `.part` files. | `FileStorageService.clearTemporaryCache` | **PASSED** |
| **Hardcoded English UI strings** | Buttons, statuses, dialogs, and settings were hardcoded in English. | Localized all UI strings across English, Arabic (with RTL), and French. | `test/settings_and_localization_test.dart` | **PASSED** |
| **Lack of Physical Book support** | App only treated books as downloadable digital files. | Added `isPhysical`, ISBN, publisher, publication year, physical ownership toggle, and purchase wishlist management. | `test/book_source_test.dart` | **PASSED** |
| **Debug signing used for Release build** | `android/app/build.gradle.kts` hardcoded `signingConfig = signingConfigs.getByName("debug")`. | Configured Gradle to read signing keys safely from `android/key.properties`, with sample template and `.gitignore` protection. | `android/app/build.gradle.kts` | **VERIFIED** |
| **Lack of Provider diagnostics** | Users had no way of knowing which online libraries were reachable or their response times. | Created Provider Diagnostics in Settings and Discover screen, measuring latency and connection health across all 6 providers. | `SourceAggregator.testAllSources()` | **PASSED** |
